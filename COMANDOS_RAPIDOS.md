# ⚡ Comandos Rápidos para GitHub

## 🚀 Sequência Completa (Copie e Cole)

```bash
# 1. Inicializar
git init

# 2. Adicionar arquivos
git add .

# 3. Commit
git commit -m "Initial commit: Scripts para acelerar cursos e-learning"

# 4. Conectar ao GitHub (SUBSTITUA USERNAME e REPO_NAME)
git remote add origin https://github.com/USERNAME/REPO_NAME.git

# 5. Renomear branch
git branch -M main

# 6. Enviar
git push -u origin main
```

# 📜 Scripts Disponíveis

## Scripts Principais

### ⭐ `desbloquear_botoes.js` (Recomendado)
**Uso:** Apenas desbloqueia botões, você controla quando avançar

**Quando usar:**
- Quer controle total
- Prefere avançar manualmente
- Máxima segurança

### `acelerar_curso.js`
**Uso:** Aceleração completa com avanço automático

**Quando usar:**
- Quer automatização total
- Não se importa com detecção
- Curso próprio/teste

### `acelerar_curso_STEALTH.js`
**Uso:** Versão com menor chance de detecção

**Quando usar:**
- Quer acelerar mas com cuidado
- Velocidade moderada (4x)
- Simula interações

### `acelerar_NARRADOR.js`
**Uso:** Focado em acelerar narração e desbloquear slides

**Quando usar:**
- Slides bloqueados por narrador
- Quer acelerar áudio especificamente

## Scripts de Suporte

- `diagnostico_rapido.js` - Diagnóstico de problemas
- `teste_rapido.js` - Testes manuais
- `RESTAURAR_SETTIMEOUT.js` - Corrige setTimeout quebrado

## Como Escolher

1. **Quer só desbloquear?** → `desbloquear_botoes.js`
2. **Quer acelerar tudo?** → `acelerar_curso.js`
3. **Quer acelerar com cuidado?** → `acelerar_curso_STEALTH.js`
4. **Problema com narrador?** → `acelerar_NARRADOR.js`
